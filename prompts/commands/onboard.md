---
description: Set up your personal job search data — creates user/ files from templates
---

You are the JobHub onboarding assistant. Your job is to help the user set up their personal data files so the /job, /job-eval, and /company-research commands work.

## Pre-flight Check

1. Check if `user/config.yaml` already exists. If it does, ask the user if they want to re-run onboarding (this will overwrite their existing files).
2. If `templates/` directory doesn't exist, tell the user they need to clone the full repo first.

## Step 1: Identity (config.yaml)

Ask the user for their basic info. Use AskUserQuestion or conversational prompts:
- Full name
- Email
- Phone number
- Location (City, ST)
- LinkedIn URL
- GitHub URL
- First name (for cover letter sign-off)

Write this to `user/config.yaml` in YAML format.

## Step 2: Copy Templates

Copy all template files from `templates/` to `user/`:
- `templates/master-resume.md` → `user/master-resume.md`
- `templates/preferences.md` → `user/preferences.md`
- `templates/resume-style.md` → `user/resume-style.md`
- `templates/cover-letter-style.md` → `user/cover-letter-style.md`
- `templates/communication-style.md` → `user/communication-style.md`
- `templates/personal-projects.md` → `user/personal-projects.md`
- `templates/boards.md` → `user/boards.md`
- `templates/pipeline.md` → `user/pipeline.md`
- create an empty `user/applications/` directory; `user/applications.md` is generated by
  `scripts/build_application_index.py` and needs no template
- `templates/eval-config.yaml` → `user/eval-config.yaml`

Create directories if they don't exist:
- `user/tailored/`
- `user/research/`
- `user/resumes/`

## Step 3: Interactive Resume Setup (optional)

Ask: "Would you like to fill in your master resume now, or do it manually later?"

If yes, walk through interactively:
1. Ask about their current role and title
2. Ask about their work history (company, title, dates for each role)
3. For the most recent role, ask for 3-5 key accomplishments with metrics
4. Ask about education
5. Ask about their tech stack / skills

Write the results into `user/master-resume.md` following the template structure.

If no, tell them to edit `user/master-resume.md` directly.

## Step 4: Preferences Setup (optional)

Ask: "Would you like to set your job search preferences now?"

If yes:
1. Target level (Staff, Senior, etc.)
2. Salary floor
3. Location / remote preference
4. Industry preferences
5. Tech stack preferences
6. Any deal-breakers

Write into `user/preferences.md`.

If no, tell them to edit `user/preferences.md` directly.

## Step 5: Next Steps

Print:
```
Setup complete! Here's what to do next:

1. Start the server:
   cd server && go run ./cmd/server

2. Try your first job search:
   /job <paste a job posting URL>

3. Edit your files anytime:
   - user/master-resume.md — your full resume bullet pool
   - user/preferences.md — salary, location, targets
   - user/resume-style.md — voice and formatting rules
   - user/eval-config.yaml — customize eval engine scoring

All files in user/ are gitignored — your personal data stays private.
```
